# EventTenda ID (Vue 3 + Tailwind CSS v4 + Vite)

Jalankan lokal:  npm install && npm run dev   (buka http://localhost:5173)
Build produksi:  npm run build                (hasil di folder dist/)
Preview build:   npm run preview

Ubah data bisnis (nama, WA, alamat, peta) di src/config.js.
Ubah produk di src/components/ProductCatalog.vue, harga di PriceCalculator.vue.
Deploy: unggah isi folder dist/ ke Netlify, Vercel, Cloudflare Pages, atau hosting statis (cPanel).
